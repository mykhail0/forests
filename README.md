# Forests

## Introduction

There are many forests growing in the world. There are many trees in every
forest. On each tree many animals can live. Each forest has a unique name. Every
tree in a forest has a unique name. Every animal living on a tree has a unique
name. This is a program that reproduces this world.

## Detailed description of functionality

After the launch of the program, there are no forests, trees nor animals. The
program reads data from the standard input and performs the following commands.
In these commands, the parameter `forest` is the name of the forest, parameter
`tree` is the name of the tree, and the parameter `animal` is the name of the
animal. The correct names are strings of non-whitespace ASCII characters with
codes from 33 to 255. The name of a correct command and its parameters are
separated by whitespace characters (characters `' '`, `'\t'`, `'\v'`, `'\f'`,
`'\r'` in C with respective ASCII codes 32, 9, 11, 12, 13). Each valid command
appears in a separate line ending with `'\n'` in C, ASCII code 10. Whitespaces
at the beginning and end of the lines are ignored.

### `ADD`

- `ADD forest` - add a forest `forest`,
- `ADD forest tree` – add a forest `forest` and a tree `tree` in that forest,
- `ADD forest tree animal` – add a forest `forest`, a tree `tree` in that forest
and an animal `animal` living on that tree.

Command `ADD` only adds entities which are missing. An attempt to add something
that already exists is ignored.

### `DEL`

- `DEL` – remove all forests, all trees and all animals,
- `DEL forest` – removes the forest `forest` and every tree and animal which
live in it,
- `DEL forest tree` – removes the given tree in the given forest and all animals
on that tree,
- `DEL forest tree animal` – removes the given animal living on the given tree
in the given forest.

Command `DEL` only removes entities which exist. An attempt to remove something
that does not exist is ignored.

### `PRINT`

- `PRINT` - print all forests,
- `PRINT forest` – print all the trees in the given forest,
- `PRINT forest tree` – print all animals from the given tree in the given
forest.

Command `PRINT` prints the names of entities sorted in a lexicographically
(according to extended ASCII codes) increasing order, each name in a separate
line. If there are no entities to be printed, nothing gets printed.

### `CHECK`

- `CHECK forest` – check whether there is a forest with the given name,
- `CHECK forest tree` – check whether there is a tree with the given name in the
given forest,
- `CHECK forest tree animal` – check whether on the given tree in the given
forest there is an animal with the given name.

In a `CHECK` command a wildcard `*` can be given as a parameter except for the
last parameter. The asterisk is a meta-character that matches any name.

Additionally, the following lines are ignored:

- empty lines,
- lines consisting of whitespace characters,
- lines starting with `#`.

## Program's output and error handling

Output:

- a line containing `OK` for successful execution of an `ADD` or a `DEL`
command,
- a line containing either `YES` or `NO`, depending on the result of the command
for successful execution of a `CHECK` command,

The program prints error information to standard diagnostic output. If an input
line is wrong, e.g. wrong command name or bad number of parameters, a line with
the word `ERROR` is logged.

The program ends after processing all commands from the input.

## Building

A [Makefile](Makefile) is supplied

Project works for a Linux system with a working gcc compiler, to run tests you
should have [valgrind](https://valgrind.org/). A [Makefile](Makefile) with a
default compilation command is supplied. It also has phony targets clean and
test. `make clean` removes all files generated by `make` including the resulting
binary. Running `make` produces a `forests` binary.

### Testing script

There is a testing script supplied which runs `prog` for every `dir/*.in` file,
compares outputs with corresponding files in `dir/*.out` and `dir/*.err` and
prints which tests were successful and which failed for the following
invocation:

```bash
./test.sh prog dir
```

Target `make test` makes use of this script.
